{%- comment -%} Gate pages' script. Every form works without it as a plain POST; with it, the page stays put: - wordmark: the fewest lines (breaking at spaces only) whose longest line, set to the width, reads as a name; - coming soon: checks the address and consent first, then posts to /notify and reads the outcome (notify_state) from the page the platform sends back; only "ok" shows the thank-you, anything else (no state included) is an error; - password: Show/Hide; posts to /password; the page coming back as the password page means it failed (its message is shown); anything else means the store opened (the outline fills in, then the browser follows); - maintenance: every 30 seconds fetches this address again. The store is back when a storefront page comes back without this page's marker, whatever the status code (the platform answers maintenance with 503). Never reloads by itself. {%- endcomment -%}
