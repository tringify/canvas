Styles: dropdown (native selects), links (inline text buttons), pill (country code and currency code; opens a short list beside it), modal (country codes with names in a centred dialog), sheet (a side sheet with search; every list is a bottom sheet on phones). Theme settings choose flags, how currencies show and language names or codes. Every choice posts localization_set; the list styles' dialog is a , which keeps focus inside it and closes on Escape. Over ten countries or languages, that list gets a search (the sheet always searches countries); up to ten languages show as chips, more as a list.
