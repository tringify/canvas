{%- comment -%} Phone field with a searchable country picker (country code, name and dial code from ctx.phone_countries; the section needs phone_countries and customer_settings in ctx_needs). Set every input before each use, since assigns carry over: cv_ph_id (unique id), cv_ph_name (the field the action takes), cv_ph_value (saved number, E.164), cv_ph_label, cv_ph_required and cv_ph_disabled (true/false), cv_ph_country (ISO code to start from when it is a phone country; then the store's default_phone_country, then the first country), cv_ph_describedby (extra hint id or blank), cv_ph_auto (autocomplete, blank: tel). The script sends one E.164 number (+ and digits) under cv_ph_name.
